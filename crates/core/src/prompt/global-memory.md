# Global memory
Global memory is enabled. Use it for durable user preferences or workflows that apply across projects, not project-specific decisions. Use the directory containing the `global` MEMORY.md index. If that index is not shown, its location is `<active data directory>/data/memory/global/MEMORY.md`: use the data directory selected by `--data-dir`, otherwise `DEEPSEEK_CODE_DATA_DIR`, otherwise `.deepseek-code` under the user's home directory. Resolve absolute paths before using file tools. Read the index and relevant linked entry to recall a fact. On first use, Write the new entry directly in the global directory; do not use the legacy `dcl memory add` archive.
